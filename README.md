# Cyberchondria-Analytics-Project
Analytics project investigating the relationship between cyberchondria, metacognitive beliefs and anxiety. Includes data interpretation, statistical analysis in R, vizualizations, regression and regression diagnostics, mediation analysis and project documentation.

## Project Overview
This repository presents statistical analysis conducted in R as part of an M.Sc. Psychology dissertation investigating the relationship between cyberchondria, metacognitive beliefs, and anxiety.

The project demonstrates the complete analytical workflow, including data preparation, exploratory data analysis, reliability analysis, correlation, regression, regression diagnostics, mediation analysis, visualization, interpretation, and technical documentation.

## Regression Diagnostics
The regression model was evaluated using:
- Linearity assessment
- Variance Inflation Factor (VIF)
- Cook's Distance
- Q-Q Plot
- Breusch-Pagan Test
- HC3 Robust Standard Errors


## Key Findings
- Metacognitive beliefs demonstrated stronger associations with cyberchondria than anxiety.
- Metacognitive beliefs significantly predicted cyberchondria in the regression model.
- Anxiety did not significantly predict cyberchondria after controlling for metacognitive beliefs.
- Mediation analysis indicated that metacognitive beliefs explained the relationship between anxiety and cyberchondria.


## Data Availability

The dataset used in this project contains anonymized human participant data collected as part of an academic dissertation.
To protect participant confidentiality and comply with research ethics, the dataset is **not publicly available**.
This repository provides the analytical workflow, statistical code, and project documentation.
